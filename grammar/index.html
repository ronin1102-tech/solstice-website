Grammar tool

Grammarly, without the cloud.

A grammar checker that doesn't send your writing to someone else's server. It runs a local LanguageTool instance, checks your grammar as you type in Chrome, and keeps every word on your machine.

Why

The problem with cloud grammar checkers.

To check your writing, most grammar tools send it to their servers. Every email, every draft, every message — read by a machine you don't own.

The cloud

Your text travels to a server to be checked. Here, it travels to 127.0.0.1 and stops.

The subscription

Premium writing help usually means a monthly bill. This is free — forever, and in the open.

The data

No account, no cloud processing, no data collection. Your words stay yours.

How it works

Three pieces. One machine.

A Chrome extension sends the text you're editing to LanguageTool running on localhost. The answer comes back as underlines. Nothing else is in the loop.

  • The engine binds to 127.0.0.1 only. A full-life network audit of the server process showed zero bytes in or out.
  • The extension's permissions allow only localhost — Chrome blocks every other origin, so it can't phone home even by accident.
  • Password and credit-card fields are skipped before any text is sent.
  • It never rewrites your text without your click.

Install

Five steps, one time.

Every command here was run on the target machine — a 2012 MacBook Pro on Catalina. The full guide lives in the repo's README.

  1. Get the repo

    git clone https://github.com/ronin1102-tech/grammar-tool.git cd grammar-tool

  2. Fetch the engine

    Downloads pinned LanguageTool and Java, verifies both by checksum, then runs a real grammar check as a smoke test. About five minutes.

    sh scripts/fetch-engine.sh

  3. Build the launcher

    Produces LWA.app in the project folder.

    sh scripts/make-app.sh

  4. Start the engine

    The first time, right-click LWA.app → Open. After that, double-click. You'll get a “Writing engine ready.” notification.

  5. Load the extension

    Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the repo's extension/ folder. It shows up as Local Writing Assistant. Reload any open tabs once.

macOS Catalina 10.15+Chrome 128Disk ~1.4 GBAdmin password not needed
